## 1. Описание предметной области

Портал «Конференции.РФ» — информационная система для бронирования помещений (аудитория, коворкинг, кинозал) под проведение Всероссийских конференций.

---

## 2. Выделенные сущности

| № | Сущность | Назначение |
|---|----------|------------|
| 1 | Пользователь (user) | Хранит данные зарегистрированных пользователей |
| 2 | Мероприятие (event) | Информация о помещениях для конференций |
| 3 | Статус (status) | Справочник статусов заявки |
| 4 | Заявка (request) | Связывает пользователя и мероприятие |
| 5 | Отзыв (review) | Обратная связь о проведённом мероприятии |

---

## 3. Описание таблиц с указанием полей, типов и ключей

### Таблица 1: user (Пользователь)

| Поле | Тип данных | Ограничения |
|------|------------|-------------|
| id | INTEGER | PK, AUTOINCREMENT |
| login | VARCHAR(50) | UNIQUE, NOT NULL |
| password_hash | VARCHAR(255) | NOT NULL |
| email | VARCHAR(100) | UNIQUE, NOT NULL |
| phone | VARCHAR(18) | NOT NULL |
| role | VARCHAR(20) | NOT NULL, DEFAULT 'user' |

### Таблица 2: event (Мероприятие)

| Поле | Тип данных | Ограничения |
|------|------------|-------------|
| id | INTEGER | PK, AUTOINCREMENT |
| name | VARCHAR(200) | NOT NULL |
| date | DATE | NOT NULL |
| place | VARCHAR(200) | NOT NULL |
| description | TEXT | — |

### Таблица 3: status (Статус)

| Поле | Тип данных | Ограничения |
|------|------------|-------------|
| id | INTEGER | PK, AUTOINCREMENT |
| name | VARCHAR(50) | UNIQUE, NOT NULL |

### Таблица 4: request (Заявка)

| Поле | Тип данных | Ограничения |
|------|------------|-------------|
| id | INTEGER | PK, AUTOINCREMENT |
| user_id | INTEGER | FK → user(id), NOT NULL |
| event_id | INTEGER | FK → event(id), NOT NULL |
| status_id | INTEGER | FK → status(id), DEFAULT 1 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP |

### Таблица 5: review (Отзыв)

| Поле | Тип данных | Ограничения |
|------|------------|-------------|
| id | INTEGER | PK, AUTOINCREMENT |
| request_id | INTEGER | FK → request(id), UNIQUE, NOT NULL |
| text | TEXT | NOT NULL |
| rating | INTEGER | CHECK (1–5) |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP |

---

## 4. Первичные и внешние ключи

| Таблица | PK | FK |
|---------|-----|-----|
| user | id | — |
| event | id | — |
| status | id | — |
| request | id | user_id → user(id), event_id → event(id), status_id → status(id) |
| review | id | request_id → request(id) |

---

## 5. Связи между сущностями

| № | Связь | Тип | Обоснование |
|---|-------|-----|-------------|
| 1 | Пользователь → Заявка | 1:M | Один пользователь — много заявок |
| 2 | Мероприятие → Заявка | 1:M | Одно мероприятие — много заявок |
| 3 | Статус → Заявка | 1:M | Один статус — много заявок |
| 4 | Заявка → Отзыв | 1:1 | Одна заявка — один отзыв |
| 5 | Пользователь ↔ Мероприятие | M:N | Реализуется через таблицу Заявка |
