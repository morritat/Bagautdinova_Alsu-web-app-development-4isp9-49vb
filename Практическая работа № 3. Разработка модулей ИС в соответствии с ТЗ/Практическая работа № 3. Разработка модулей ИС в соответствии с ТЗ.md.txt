## 5. Реализованные модули

### 5.1. Модуль регистрации (`/api/auth/register`)

Реализована полная валидация полей согласно ТЗ:

| Поле | Правило валидации | Пример ошибки |
|---|---|---|
| Логин | Латиница + цифры, ≥ 6 символов, уникален | «Логин должен содержать минимум 6 символов» |
| Пароль | ≥ 8 символов, хешируется | «Пароль должен содержать минимум 8 символов» |
| Email | Валидный формат, уникален | «Некорректный email» |
| Телефон | Формат `8(XXX)XXX-XX-XX` | «Телефон в формате 8(XXX)XXX-XX-XX» |
| Роль | По умолчанию `user` | — |

**Ключевой код (backend/models/user.py):**

```python
def save(self) -> tuple:
    ok, msg = self.validate()
    if not ok:
        return False, msg
    if self.login_exists():
        return False, "Пользователь с таким логином уже существует"
    password_hash = generate_password_hash(self.password)
    user_id = self.db.execute(
        """INSERT INTO user (login, password_hash, email, phone, role)
           VALUES (?, ?, ?, ?, ?)""",
        (self.login, password_hash, self.email, self.phone, self.role)
    )
    self.id = user_id
    return True, user_id

5.2. Модуль авторизации (/api/auth/login)
Проверка логина и пароля через check_password_hash.
Создание сессии (session['user_id'], session['role']).
Перенаправление в зависимости от роли:
user → /dashboard
admin → /admin
Сообщения об ошибках при неверных данных.
5.3. Модуль создания заявки (/create_request)
Форма с выпадающим списком помещений (аудитория, коворкинг, кинозал).
При отправке создаётся запись в таблице request со статусом «Новая» (status_id = 1).
Заявка привязывается к текущему авторизованному пользователю.
5.4. Модуль просмотра заявок (/dashboard)
JOIN-запрос связывает request, event, status.
Пользователь видит только свои заявки.
Отображаются: №, мероприятие, дата, место, статус, дата создания.
5.5. Панель администратора (/admin)
Доступ по учётным данным: логин Conf2027, пароль Demo77.
Просмотр всех заявок всех пользователей.
Смена статуса: «Новая» → «Мероприятие назначено» → «Завершено».
Проверка роли через session.get('role') == 'admin'.
